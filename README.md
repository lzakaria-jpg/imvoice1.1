# استيراد فواتير المبيعات — قيود

أداة تحوّل ملفات فواتير العملاء (نقاط بيع، سلة، أنظمة أخرى) إلى قالب استيراد فواتير المبيعات الرسمي في قيود، مع تحقق من خمس طبقات ومطابقة حسابية قبل الرفع.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء للنشر — المخرج في dist/
npm test         # اختبارات وحدة المنطق الحسابي
npm run test:real  # تشغيل على ملف عميل حقيقي والتحقق من المخرج
```

كل المعالجة تتم في المتصفح. لا يُرفع أي ملف إلى أي خادم.

## المسار

1. **المراجع** — قالب قيود من حساب العميل، ملف العملاء، ملف المنتجات بكمياتها
2. **ملف العميل** — الرفع وربط الأعمدة (كشف تلقائي قابل للتعديل)
3. **المطابقة** — العملاء، المنتجات، طرق الدفع، المواقع
4. **التحقق** — الملاحظات، المطابقة الحسابية، الكميات
5. **التصدير** — قالب قيود، المرتجعات منفصلة، تقرير التحقق

## القرارات الهندسية

هذه القرارات تحدد أرقام المخرج. كل واحد منها مُثبت على بيانات حقيقية (220 فاتورة، 1085 بنداً، 631,877.89 ر.س).

### التسعير شامل الضريبة

مصادر نقاط البيع تسعّر شاملاً الضريبة. على ملف الاختبار: 1079 بنداً من 1159 يعطي سعر وحدة نظيفاً بالأساس الشامل، مقابل 1012 بالأساس غير الشامل. اعتماد الأساس الشامل يقلل انحراف التقريب.

### الخصم بالنسبة المئوية دائماً

`قيمة الخصم` تبقى فارغة. السبب حاسم: **النسبة محايدة تجاه أساس الاحتساب** — خصم 10% هو 10% سواء حُسب على مبلغ شامل أو غير شامل، لأن الطرفين ينضربان بنفس المعامل.

هذا يلغي غموضاً حقيقياً: عند `شامل الضريبة = نعم`، لا يوجد توثيق يحدد هل قيود يفسّر `قيمة الخصم` على الأساس الشامل أم غير الشامل. قياس الفرق بين التفسيرين على ملف الاختبار: **9,091 ر.س**. النسبة تتجنب هذا الاحتمال كلياً.

كما يضمن عدم مخالفة قاعدة قيود الصريحة: لا يُقبل الخصم بالنسبة والقيمة معاً في نفس البند.

### دقة سعر الوحدة: أربع خانات

| الدقة | فواتير منحرفة | أقصى انحراف | مجموع الانحراف |
|---|---|---|---|
| 4 خانات | 10 / 220 | 0.04 ر.س | 0.67 ر.س |
| خانتان | 21 / 220 | 0.12 ر.س | 1.30 ر.س |

الانحراف المتبقي مصدره تقريب نظام العميل نفسه، لا التحويل. إن رفض قيود الدقة الأعلى، الخيار قابل للتبديل من شاشة التصدير.

### تكرار بيانات الفاتورة في كل صف

توثيق قيود يذكر التكرار صراحةً، ويدرج عدمه ضمن أسباب فشل الصفوف. نص الـ Data Validation داخل القالب يقول العكس ويُعتبر بقايا نسخة أقدم. الخيار قابل للتبديل.

### فصل المرتجعات

الفواتير ذات القيم السالبة ليست فواتير مبيعات، ولها مسار مستقل في قيود كإشعارات دائنة. تُفصل في ملف خاص ولا تُدرج في ملف الاستيراد.

### توريث الضريبة للبنود ذات الوعاء الصفري

البند الذي وعاؤه الضريبي صفر (منتج مجاني، رسوم بصفر، خصم 100%) لا يمكن اشتقاق نسبته حسابياً. التسلسل: نسبة البند ← الضريبة السائدة في نفس الفاتورة ← الضريبة الافتراضية. وكل بند ورث حكمه يُبلَّغ عنه.

### تدرج خطورة فرق الرأس عن البنود

فرق بحدود القروش (≤ 0.05) أصله تقريب في نظام المصدر ويُعامَل كتحذير. الفرق الأكبر يعني أن رأس الفاتورة لا يمثّل بنودها، ويُعامَل كخطأ فادح يوقف الفاتورة.

## طبقات التحقق

| الطبقة | ما تفحصه |
|---|---|
| 0 | مطابقة القالب المرفوع للنسخة الرسمية، وامتلاء قوائمه — يكشف «النموذج القديم» الذي يوقف الاستيراد |
| 1 | الحقول الإلزامية، الأطوال، الصيغ، النطاقات، القوائم المعتمدة، قاعدة الخصم المزدوج |
| 2 | تطابق بيانات الفاتورة بين صفوفها، وترتيب التواريخ |
| 3 | حدود الملف: غير فارغ، ولا يتجاوز 5000 صف |
| 4 | المطابقة الحسابية لكل فاتورة، وكفاية الكميات المتراكمة عبر كل الفواتير |

نقص الكمية يُعامَل كخطأ فادح لأن قيود يرفض الفاتورة كاملة إذا لم تكفِ كمية منتج مخزَّن.

## المخرجات

**قالب قيود** — بنفس تنسيق النسخة الرسمية: الرؤوس الـ19، الدمج `A1:J1` و`K1:S1`، الألوان `#122664` و`#00DAF9` و`#004586`، خط Arial، ورقة `do_not_edit` بحالة `veryHidden`، و13 قيد تحقق.

**المرتجعات** — البيانات الأصلية كما هي، لمعالجتها كإشعارات دائنة.

**تقرير التحقق** — الملخص، الملاحظات كاملة، المطابقة الحسابية لكل فاتورة، حالة الكميات.

## ملاحظات على مصادر نقاط البيع

نقاط تكررت في بيانات حقيقية وتستحق الانتباه:

- اسم الفرع في نظام العميل قد يختلف عن اسم الموقع في قيود («الفرع الرئيسي» مقابل «المركز الرئيسي») — يحتاج قرار مطابقة صريح
- فواتير سلة قد تصل بلا موقع
- فواتير نقاط البيع قد تصل بلا اسم عميل — تحتاج عميلاً افتراضياً
- رسوم الشحن والدفع عند الاستلام تصل بلا رمز منتج، وتحتاج منتجات خدمية مضافة مسبقاً في قيود
- صفوف الدفع قد تتكرر في التصدير، وهو لا يؤثر على الاستيراد لكنه يدل على خلل في المصدر
